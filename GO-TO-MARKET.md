# ShieldCortex — Go-To-Market Playbook

## Strategic Position

Palo Alto Networks warned about persistent memory attacks on AI agents (Jan 31, 2026). Every AI agent developer read that warning. **ShieldCortex is the cure.**

---

## Viral Growth Angles

### 1. 🎬 Live Hack Demo
Record a video showing an AI agent getting memory-poisoned in real-time, then show ShieldCortex blocking it.

**Format:** "Your AI agent right now → Your AI agent with ShieldCortex"

Short, scary, shareable. Post on X/Twitter, YouTube Shorts, LinkedIn.

### 2. 🆓 Free Tier is the Growth Engine
Open-source the core (memory firewall + basic audit). Devs adopt it, talk about it, blog about it.

**Paid tiers for enterprise features:**
- Fragmentation detection
- Dashboards & monitoring
- Compliance reporting (GDPR, SOC2)

**Pricing:**
| Tier | Price | Features |
|------|-------|----------|
| Free | £0 | Memory Firewall, Basic Audit |
| Pro | £29/mo | + Fragmentation Detection, Sensitivity Classifier |
| Team | £99/mo | + Dashboard, Trust Scoring, Team Management |
| Enterprise | £499+/mo | + Custom Policies, SLA, Dedicated Support |

### 3. 🤖 Moltbook is Ground Zero
30,000+ agents on Moltbook, zero memory security. If ShieldCortex integrates as a plugin/hook for Moltbook agents, every agent owner becomes a potential customer.

They've already seen agents go rogue. The need is proven.

### 4. 🔍 "Is Your AI Agent Compromised?" — Free Scanner
Free scanning tool that analyses an agent's existing memory for signs of poisoning. Like a virus scan for AI memory.

**Why this goes viral:**
- People WILL run it out of curiosity
- It becomes the entry point to the paid product
- Generates shareable results ("My agent had 3 suspicious memories!")
- Creates urgency to install the full protection

**This is probably the fastest viral path — give people something to DO, not just read.**

### 5. 📝 Dev.to / Hacker News / Reddit Launch
Technical deep-dive post: **"We Found 5 Ways to Poison AI Agent Memory. Here's How We Stop Them."**

Educational content that positions Drakon Systems as the authority on AI memory security. Not a sales pitch — a genuine contribution that happens to have a product behind it.

### 6. 🐦 Tweet Thread Timing
Drop while Palo Alto's warning is still fresh:
- Tag the Palo Alto researchers
- Quote their findings
- "They identified the problem. We built the solution."
- Link to the free scanner + GitHub repo
